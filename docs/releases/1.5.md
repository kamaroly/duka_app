# Risiti app 1.5 — New logo (September 2026)

For how each feature works now, see the [documentation](../README.md).

Android `versionName` 1.5, `versionCode` 6. Branch: `transactions`.
Installs over 1.4 (same package, `com.example.risiti_app`), keeping your data.

## What's new

- **App icon:** the new Risiti logo, a white receipt on a teal gradient
  (#2A4F4A to #0F2622). On Android it's still an adaptive icon with a
  monochrome layer for themed icons (Android 13+).
- **Splash screen:** the new logo on the same teal while the app starts.
  The Android 12+ system splash and the iOS launch screen use the
  gradient's middle, #1C3A36.

The artwork is `logos/risiti_logo.svg` (from `logos.zip`); the PNGs were
rendered from it. The website uses the same logo (Risiti server, same day).
