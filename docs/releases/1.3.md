# Risiti app 1.3 — New app id, tidier list (September 2026)

For how each feature works now, see the [documentation](../README.md).

Android `versionName` 1.3, `versionCode` 4. Branch: `transactions`.

## Installs as a new app

The app is now `risiti_app`, package **`com.example.risiti_app`** (was
`com.example.duka_app`). Android treats it as a different app:

- It installs next to 1.2 rather than over it. Data only on the old app
  stays there; anything synced comes back after signing in to the new one.
- Google sign-in needs an Android OAuth client for `com.example.risiti_app`
  with the release key's SHA-1 (unchanged,
  `E4:C4:01:37:06:56:7C:F3:2E:81:96:07:A1:3E:EE:DE:DF:25:B8:8B`). See
  [Signing in](../sign-in.md).
- Push notifications need the new package registered in Firebase and a new
  `google-services.json`.

## What's new

### A shorter transaction card
- **KRA receipts** get a small green "KRA" tag. Whether KRA has verified
  the receipt is shown on its sheet.
- **Status as icons** on the date row, next to the sync cloud: an amber tick
  while a claim waits for approval, a green tick once approved, and a
  payments icon once paid. Rejected is still a slim pill.

### Order
The home list shows the most recently added or changed transactions first.
