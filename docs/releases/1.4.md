# Risiti app 1.4 — New icon and splash screen (September 2026)

For how each feature works now, see the [documentation](../README.md).

Android `versionName` 1.4, `versionCode` 5. Branch: `transactions`.
Installs over 1.3 (same package, `com.example.risiti_app`).

## What's new

- **App icon:** the Risiti logo, a bank note with a green tick on the brand
  green (#1F6B4A). On Android it's an adaptive icon, so the launcher shapes
  it (circle, squircle…), with a monochrome layer for themed icons
  (Android 13+).
- **Splash screen:** while the app starts, the logo on the brand green
  instead of a black screen. On Android 12+ the system splash shows the
  icon on the same green first.
- Behind the status and navigation bars, the app's own background instead
  of black.

The logo artwork is from `logos.zip` (SVG); the PNGs were rendered from it.
The website uses the same logo (Risiti server, same release day).
